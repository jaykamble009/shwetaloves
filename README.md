# For Shweta — A Thoughtful Question 🌹

An interactive romantic proposal web experience designed with smooth animations, ambient romantic piano, and heartfelt storytelling.

## Features
- **Ambient Romantic Piano**: Interactive audio powered by Web Audio API synthesizers.
- **Floating Rose Petals**: CSS-driven atmospheric particle effects.
- **Interactive Envelope & Wax Seal**: Chapter 1 letter reveals on opening the wax seal.
- **Interactive Surprise Gift Box**: Chapter 2 interactive 3D gift box with light animation.
- **Heartfelt Proposal**: Dual-response flow with celebration particles or a 15-second reflection timer.

## How to View
Open `index.html` in any modern web browser or host on GitHub Pages.
